The problem

Companies decide on designs using simulation results. Checking those results is slow, manual and often skipped, and the numbers in reports are copied by hand, so nobody can later prove where they came from.

What SimProof does

It reads the simulation files, runs 32 automatic checks for common setup and physics mistakes, and writes a report in which every number links back to the exact file it came from.

Why it matters

A wrong number can lead to a failed part, a costly redesign or a safety risk. SimProof gives engineers, managers and customers proof instead of trust.

It has already caught a real error

In a commercial heat study, SimProof found that the simulation had switched off 5 to 7 of the 10 heat loads in each model. The simulation finished normally, and the first report built on it was wrong. SimProof also worked out the values the study should have used.

For engineers: the details

Before the solve and after it

32 deterministic checks run on the raw solver files, with no AI deciding anything. A pass means no setup or balance error was found; it does not approve the design.

Pre-Solve Setup Audit

Catch setup mistakes before using compute time

Reads your input deck before you queue cluster time and solver licences:

  • Unit system: Flags models whose unit system or temperature scale cannot be determined.
  • Zero and pulsed loads: Flags loads that are zero for the whole solve, and pulsed loads that are zero at the instant a steady solve samples them.
  • Constraints: Detects static models with no displacement constraint, and mesh parts with no path to a support.
  • Material values: Checks that the elastic modulus is positive, Poisson's ratio lies between −1 and 0.5, and density is present when inertia loads are applied.
Post-Solve Validity Audit

Check the physics after the solver exits

Answers the question that matters: did the solver solve the right problem?

  • Force and energy balance: Checks that applied loads match solver reactions: within 1 % for thermal models and 0.1 % for structural force loads (pressure, gravity and rotation coming soon).
  • Moment balance: Checks net moment equilibrium (Σ M = 0) about the global origin.
  • Work and strain energy: Checks that external work matches elastic strain energy (½ W ≈ U).
  • Result set completeness: Confirms every declared load step and substep was solved, converged and stored.
  • Stress and displacement sanity: Checks that von Mises stresses and displacements are finite and physically possible.

From solver file to signed-off number

Four steps, each one deterministic. A language model can explain a finding; it never makes one.

  1. 1

    Read

    Readers turn input decks, solver logs and result files into one solver-neutral study. Every value keeps its file, its line or node, and the file's SHA-256 fingerprint. Anything a reader can't parse is listed in the report, never guessed.

    ds.dat, solve.out, file.rth
  2. 2

    Check

    Checks are plain Python with no language model in the loop. Each has a written spec, cites the sources its method rests on, and returns the evidence behind its finding.

    static_time_dependent_load: fail
  3. 3

    Report

    The report template can only print a number together with its evidence tag. An appendix lists the source file, location and fingerprint behind every tag.

    33.33 mW/mm^2 [E8]
  4. 4

    Verify

    simproof verify re-reads a finished report and compares every tagged value with its evidence. Edited numbers and numbers without a tag are flagged.

    tagged_values: 16, mismatches: 0

    What SimProof checks today
    
          
    
            32 deterministic checks, grouped by where a mistake enters a study. Each one has a written spec
            and names the sources its method rests on. A check is marked validated once it has given the
            expected result on real solver output.
          
    
        
    

        
    
          
    Solvers
    
          
    Ansys Mechanical and MAPDL: input deck, solver output, .rth and .rst result files. Early support, not yet validated on real solver output: Nastran (bulk data deck and .f06 output), CalculiX (.inp deck, .frd results and .dat reaction totals) and Abaqus (.inp deck and run messages).
    
          
    Analyses
    
          
    Static structural, steady-state and transient thermal, modal
    
          
    Reports
    
          
    Markdown, Word and PDF, with an evidence tag on every number, an appendix listing each tag's source, and a credibility record that sorts the check results by ASME V&V 40 credibility factor
    
          
    Re-checking
    
          
    simproof verify compares a finished report with its evidence; simproof reverify reads the solver files again
    
          
    Sign-off
    
          
    simproof signoff records who reviewed a report and their decision: approved, changes requested or rejected
    
          
    Interfaces
    
          
    Command line, and an MCP server for Claude Code, Claude Desktop and other MCP clients. You can add your own checks in Python. Public install coming later; during the free check we run SimProof for you.
